# WealthOS Cloud
Static Supabase-powered investment dashboard.

Deploy:
1. Upload all files in this folder to the root of your GitHub repository.
2. In Vercel, Add New > Project > import the repository.
3. Framework Preset: Other.
4. Leave Build Command empty.
5. Deploy.

Important: Never add a Supabase service_role/secret key. This project contains only a browser-safe publishable key.
